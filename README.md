# 🚀 Student Management Servlet

A basic **Student Management System** developed using **Java Servlets, HTML, and Apache Tomcat**.  
This project demonstrates the fundamentals of Java Servlet development, web applications, and request-response handling.

---

## 📌 About The Project

The **Student Management Servlet** is a beginner-friendly Java web application created to understand how Servlets work in a web environment.

The project demonstrates:

- Java Servlet basics
- HTTP request and response
- Servlet URL mapping
- HTML form handling
- Web application structure
- Apache Tomcat deployment
- Eclipse Dynamic Web Project structure
